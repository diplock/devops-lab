# DevOps Lab

This repository contains my personal DevOps lab used to practice:

- Ansible automation
- Docker containers
- Kubernetes (K3s)
- GitHub Actions CI/CD
- Infrastructure as Code

## Infrastructure

Control Node:
Ubuntu VM running KVM

Managed Nodes:
- Alpine Linux VM (Kubernetes Control Plane)
- Alpine Linux VM (Worker Node)

## Tools Used

- Ansible
- Docker
- K3s Kubernetes
- GitHub Actions
